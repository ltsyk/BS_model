可视化分析

Black-Scholes模型说明

模型公式

看涨期权: C = S₀N(d₁) - Ke⁻ʳᵀN(d₂)

看跌期权: P = Ke⁻ʳᵀN(-d₂) - S₀N(-d₁)

其中:

d₁ = [ln(S/K) + (r + σ²/2)T] / (σ√T)

d₂ = d₁ - σ√T

Greeks解释

Delta: 标的资产价格变动1单位，期权价格变动

Gamma: 标的资产价格变动1单位，Delta的变动

Theta: 时间过去1天，期权价格变动（通常为负）

Vega: 波动率变动1%，期权价格变动

Rho: 利率变动1%，期权价格变动

模型假设

  • 欧式期权（只能在到期日行权）
  • 无交易成本和税收
  • 标的资产价格服从几何布朗运动
  • 波动率和无风险利率恒定
  • 标的资产不支付股息

实际应用

  • 期权定价和估值
  • 风险管理和对冲策略
  • 隐含波动率计算
  • 期权交易策略分析
  • 衍生品组合管理
